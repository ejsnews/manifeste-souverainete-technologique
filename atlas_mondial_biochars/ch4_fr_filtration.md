# Chapitre 4 — Le biochar comme matériau de filtration

> Version 1.0 — Juillet 2026

---

# Introduction

Si le biochar est aujourd'hui principalement connu pour son utilisation en agriculture, son potentiel dans le domaine de la filtration est probablement l'un de ses marchés industriels les plus prometteurs.

Grâce à sa structure poreuse, à sa grande surface spécifique et à sa chimie de surface, il peut adsorber de nombreux contaminants présents dans l'eau, les effluents industriels et certains gaz. Les performances dépendent fortement de la biomasse d'origine, de la température de thermolyse et d'éventuels traitements de surface. :contentReference[oaicite:0]{index=0}

---

# Pourquoi le biochar filtre-t-il ?

Le biochar possède un réseau complexe de pores :

- micropores (< 2 nm)
- mésopores (2 à 50 nm)
- macropores (> 50 nm)

Ces pores offrent une très grande surface interne pouvant atteindre plusieurs centaines de mètres carrés par gramme selon le procédé de fabrication.

Cette structure favorise :

- l'adsorption physique ;
- les échanges ioniques ;
- certaines réactions d'oxydoréduction ;
- le développement de biofilms dans les biofiltres. :contentReference[oaicite:1]{index=1}

---

# Les principaux contaminants

Le biochar peut être étudié pour la rétention ou la réduction de nombreux polluants :

| Famille | Exemples |
|----------|----------|
| Métaux lourds | Pb, Cd, Hg, As |
| Nutriments | NH₄⁺, PO₄³⁻ |
| Matière organique | DCO, composés organiques |
| Colorants | effluents textiles |
| Micropolluants | pesticides, résidus pharmaceutiques |
| Micro-organismes | réduction en combinaison avec d'autres procédés |

Les performances varient selon le type de biochar et les conditions d'exploitation. :contentReference[oaicite:2]{index=2}

---

# Les mécanismes d'adsorption

Plusieurs mécanismes interviennent simultanément :

- adsorption physique ;
- adsorption chimique ;
- échanges ioniques ;
- précipitation ;
- complexation de surface.

Leur importance dépend du pH, de la température, de la taille des pores et des groupes fonctionnels présents à la surface du biochar.

---

# Eau potable

Le biochar peut être intégré dans :

- filtres gravitaires ;
- colonnes filtrantes ;
- filtres multicouches ;
- procédés hybrides.

Il est généralement associé à d'autres médias filtrants afin d'améliorer les performances globales. :contentReference[oaicite:3]{index=3}

---

# Traitement des eaux usées

Les applications étudiées concernent notamment :

- stations d'épuration ;
- effluents agricoles ;
- effluents industriels ;
- eaux grises ;
- lixiviats.

Des revues récentes rapportent de bonnes performances pour l'élimination de la DCO, de l'ammonium, du phosphore et de certains pathogènes dans des colonnes filtrantes à base de biochar. :contentReference[oaicite:4]{index=4}

---

# Filtration de l'air

Le biochar est également évalué pour :

- les composés organiques volatils (COV) ;
- certaines odeurs industrielles ;
- le sulfure d'hydrogène ;
- l'ammoniac.

Selon les applications, il peut être utilisé seul ou après activation physique ou chimique.

---

# Biochar ou charbon actif ?

| Critère | Biochar | Charbon actif |
|----------|----------|---------------|
| Coût de production | Faible à moyen | Plus élevé |
| Surface BET | Moyenne à élevée | Très élevée |
| Valorisation carbone | Oui | Limitée |
| Production locale | Facile | Plus complexe |
| Applications agricoles | Oui | Rare |

Le charbon actif reste souvent plus performant pour certaines applications exigeantes, mais le biochar présente des avantages économiques et environnementaux importants, notamment lorsqu'il est produit localement.

---

# Paramètres influençant les performances

Les principaux paramètres sont :

- biomasse utilisée ;
- température de thermolyse ;
- vitesse de chauffe ;
- temps de séjour ;
- humidité ;
- granulométrie ;
- surface BET ;
- fonctionnalisation éventuelle.

---

# Régénération

Selon les contaminants captés, plusieurs approches sont envisageables :

- régénération thermique ;
- régénération chimique ;
- réemploi dans d'autres applications lorsque cela est compatible avec la réglementation.

Le choix dépend de la nature des polluants adsorbés.

---

# Perspectives industrielles

Le développement de biochars spécialement conçus pour la filtration constitue une voie de recherche active.

Les axes d'amélioration concernent notamment :

- l'augmentation de la surface spécifique ;
- le contrôle de la distribution des pores ;
- la fonctionnalisation chimique ;
- les composites biochar/minéraux ;
- les matériaux magnétiques facilitant la récupération.

Ces développements visent à élargir les applications dans le traitement de l'eau, de l'air et des effluents industriels. :contentReference[oaicite:5]{index=5}

---

# Conclusion

La filtration représente l'un des marchés à plus forte valeur ajoutée pour les biochars techniques.

À mesure que les procédés de production deviennent plus maîtrisés, il devient possible de développer des biochars optimisés pour une famille précise de contaminants plutôt qu'un matériau universel.

Cette spécialisation pourrait conduire à l'émergence de nouvelles gammes de biochars industriels, caractérisés non seulement par leur biomasse d'origine, mais aussi par leur architecture poreuse et leurs performances d'adsorption.
