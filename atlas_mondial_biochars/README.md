## Méthode

L’Atlas distingue autant que possible :

- les données établies ;
- les ordres de grandeur ;
- les observations et retours de terrain ;
- les caractéristiques annoncées par les constructeurs ;
- les hypothèses industrielles ;
- les architectures prospectives.

Lorsqu’une donnée industrielle reste ambiguë, l’Atlas conserve cette incertitude visible plutôt que d’inventer une précision. Les caractéristiques techniques et commerciales doivent être vérifiées dans leur version en vigueur au moment d’un projet.

Le biochar n’est pas présenté comme une solution universelle : sa valeur dépend de l’origine de la biomasse, du procédé, de sa qualité, de l’usage final, du territoire et du bilan de cycle de vie.
