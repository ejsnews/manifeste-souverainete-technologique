# Chapitre 5 — Vers le biochar idéal

> Version 1.0 — Juillet 2026

---

# Introduction

Existe-t-il un **biochar universel** capable de répondre simultanément aux besoins de l'agriculture, du bâtiment, de la filtration, de l'industrie et de la séquestration du carbone ?

Probablement pas.

En revanche, il est possible d'imaginer un **biochar de référence**, optimisé pour un très grand nombre d'applications industrielles.

Ce chapitre propose un cahier des charges technique destiné à orienter la recherche et le développement.

L'objectif n'est pas de décrire un produit existant, mais de définir une cible technologique.

---

# Les qualités recherchées

Le biochar idéal devrait réunir simultanément :

- une excellente stabilité chimique ;
- une forte résistance mécanique ;
- une très grande surface spécifique ;
- une faible teneur en contaminants ;
- une granulométrie contrôlée ;
- une excellente reproductibilité industrielle.

---

# Biomasses candidates

Les biomasses les plus prometteuses présentent généralement :

- une forte teneur en lignine ;
- une faible teneur en cendres ;
- une disponibilité durable ;
- une bonne homogénéité.

| Biomasse | Potentiel |
|-----------|:---------:|
| Bambou | ★★★★★ |
| Bois dur | ★★★★★ |
| Coques de noix | ★★★★★ |
| Coques de coco | ★★★★★ |
| Robinier | ★★★★☆ |
| Eucalyptus | ★★★★☆ |
| Miscanthus | ★★★☆☆ |
| Résidus forestiers sélectionnés | ★★★★☆ |

Le choix final dépend de la disponibilité locale, du procédé industriel et des applications visées.

---

# Cahier des charges proposé

| Paramètre | Objectif |
|------------|----------|
| Carbone fixe | > 85 % |
| H/Corg | < 0,30 |
| O/Corg | < 0,20 |
| Surface BET | > 500 m²/g |
| Cendres | < 5 % |
| Humidité | < 10 % |
| Granulométrie | Contrôlée |
| Métaux lourds | Très faibles |
| HAP | Sous les seuils réglementaires |

Ces valeurs constituent une cible de développement et non une spécification universelle. Elles devront être adaptées à chaque application.

---

# Les propriétés attendues

Le biochar idéal devrait offrir :

- une excellente capacité d'adsorption ;
- une forte stabilité du carbone ;
- une bonne compatibilité avec les liants cimentaires ;
- une faible variabilité entre lots ;
- une bonne aptitude à la certification.

---

# Les applications prioritaires

## Construction

Objectifs :

- stockage durable du carbone ;
- réduction de l'empreinte carbone des matériaux ;
- amélioration de certaines propriétés fonctionnelles.

Des travaux récents montrent que l'incorporation maîtrisée de biochar peut améliorer certaines propriétés des matériaux cimentaires tout en contribuant au stockage du carbone, sous réserve d'une formulation adaptée. :contentReference[oaicite:0]{index=0}

---

## Filtration

Le biochar idéal devrait présenter :

- une microporosité importante ;
- une distribution homogène des pores ;
- une grande stabilité chimique.

---

## Agriculture

Le biochar recherché devra :

- améliorer la rétention d'eau ;
- favoriser l'activité biologique ;
- limiter les pertes d'éléments nutritifs ;
- conserver une stabilité élevée sur le long terme.

---

## Industrie

Les applications potentielles comprennent :

- polymères ;
- composites ;
- caoutchoucs ;
- matériaux biosourcés ;
- supports catalytiques.

---

# Compatibilité avec les crédits carbone

Le biochar idéal devrait également :

- satisfaire aux exigences des principales certifications ;
- présenter une traçabilité complète ;
- démontrer une stabilité élevée du carbone ;
- permettre la génération de crédits carbone lorsque les conditions des référentiels sont remplies.

---

# Le rôle des unités industrielles

Les unités modernes de thermolyse ont vocation à devenir des plateformes de valorisation de la biomasse.

À partir d'une même matière première, elles peuvent produire :

- un biochar à haute valeur ajoutée ;
- un gaz de synthèse ;
- de la chaleur récupérable ;
- selon les procédés, de l'hydrogène renouvelable, du SNG ou des carburants de synthèse.

Le modèle économique dépendra de l'équilibre recherché entre ces différents produits.

---

# Une proposition de biochar de référence

Afin de faciliter les comparaisons internationales, cet atlas propose la création d'un biochar de référence fictif :

## BR-1 — Biochar de Référence

Objectif :

Servir de matériau de comparaison entre les différents procédés de production.

Le BR-1 ne constitue pas un produit commercial.

Il représente un cahier des charges ouvert destiné à évoluer avec les progrès scientifiques.

---

# Évolutions possibles

À terme, plusieurs familles pourraient être définies :

| Code | Domaine principal |
|-------|-------------------|
| BR | Biochar de référence |
| BC | Construction |
| BF | Filtration |
| BA | Agriculture |
| BI | Industrie |
| BS | Séquestration carbone |

Chaque famille pourrait être déclinée en plusieurs générations (BR-1, BR-2, BC-1, BF-1…).

---

# Conclusion

L'avenir du biochar ne réside probablement pas dans un matériau unique capable de tout faire.

Il réside plutôt dans une famille de biochars spécialisés, produits de manière reproductible, caractérisés par des propriétés mesurées et adaptés à des usages clairement identifiés.

L'objectif de cet atlas est de contribuer à cette démarche en proposant un langage commun, une classification technique et des critères de comparaison ouverts à la communauté scientifique et industrielle.
