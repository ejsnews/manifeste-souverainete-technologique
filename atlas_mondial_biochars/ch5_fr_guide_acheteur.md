# Chapitre 5 — Guide mondial de l'acheteur de biochar

> Version 1.0 – Juillet 2026

---

# Introduction

Acheter du biochar peut sembler simple.

En réalité, deux biochars vendus au même prix peuvent présenter des performances très différentes selon :

- la biomasse utilisée ;
- le procédé de thermolyse ;
- la température de production ;
- le temps de résidence ;
- le refroidissement ;
- le stockage ;
- la granulométrie ;
- l'application visée.

Le meilleur biochar n'existe donc pas.

Le meilleur biochar est celui qui est adapté à son usage.

Ce guide propose une méthode rationnelle permettant d'évaluer une offre avant toute décision d'achat.

---

# Première question : quel est votre objectif ?

Avant toute comparaison technique, il convient de définir l'application recherchée.

| Application | Objectif principal |
|--------------|-------------------|
| Agriculture | Amélioration des sols |
| Maraîchage | Rétention d'eau |
| Viticulture | Activité biologique |
| Sylviculture | Régénération forestière |
| Filtration | Adsorption |
| BTP | Béton bas carbone |
| Asphalte | Allégement et stockage carbone |
| Métallurgie | Carbone réducteur |
| Batteries | Matériaux carbonés |
| Crédits carbone | Séquestration durable |

---

# Les dix questions à poser au fournisseur

Avant toute commande importante, demander systématiquement :

✓ Quelle biomasse est utilisée ?

✓ Quelle température maximale ?

✓ Quelle durée de thermolyse ?

✓ Existe-t-il une analyse récente ?

✓ Le biochar est-il certifié ?

✓ Quel est le taux de carbone fixe ?

✓ Quel est le rapport H/Corg ?

✓ Quel est le taux de cendres ?

✓ Existe-t-il des analyses HAP et métaux lourds ?

✓ Des essais industriels ont-ils déjà été réalisés ?

---

# Les paramètres indispensables

Un fournisseur sérieux doit pouvoir communiquer les valeurs suivantes.

| Paramètre | Pourquoi ? |
|------------|------------|
| Carbone fixe | stabilité |
| Humidité | stockage |
| pH | compatibilité des sols |
| Surface BET | adsorption |
| Porosité | filtration |
| Granulométrie | mise en œuvre |
| Cendres | qualité |
| H/Corg | stabilité carbone |
| O/Corg | vieillissement |
| Conductivité | applications techniques |

---

# Les analyses chimiques

Toujours vérifier :

- HAP (Hydrocarbures Aromatiques Polycycliques)
- Cadmium
- Mercure
- Plomb
- Chrome
- Nickel
- Zinc
- Arsenic

Ces analyses sont particulièrement importantes pour les usages agricoles et les matériaux.

---

# Les certifications

Les certifications apportent une garantie supplémentaire mais ne remplacent pas l'analyse technique.

Parmi les principales références :

- European Biochar Certificate (EBC)
- International Biochar Initiative (IBI)
- référentiels nationaux
- certifications liées aux crédits carbone selon les marchés concernés

Une certification facilite la confiance mais ne dispense pas d'évaluer l'adéquation du produit à l'usage envisagé.

---

# Comparer deux offres

Ne jamais comparer uniquement :

```
€/tonne
```

Comparer plutôt :

```
€/tonne

+

qualité

+

application

+

distance

+

certification

+

carbone fixe

+

surface BET

+

performances démontrées
```

Le coût total d'utilisation est souvent plus pertinent que le prix d'achat.

---

# Les pièges classiques

Un biochar très bon marché peut présenter :

- trop de cendres ;
- une faible stabilité ;
- une biomasse médiocre ;
- une température insuffisante ;
- une forte variabilité.

À l'inverse, un biochar très coûteux n'est pas forcément le meilleur pour une application donnée.

---

# Agriculture

Pour les applications agricoles, il est conseillé de vérifier :

- le pH du sol ;
- la texture ;
- les besoins hydriques ;
- les cultures concernées.

Le biochar est généralement plus efficace lorsqu'il est préalablement mélangé avec du compost ou des matières organiques.

---

# Construction

Pour le béton ou les matériaux :

- vérifier la granulométrie ;
- contrôler l'humidité ;
- vérifier la compatibilité avec les liants ;
- demander des essais mécaniques.

Le comportement dépend fortement de la formulation finale.

---

# Filtration

Pour les applications de filtration :

les critères essentiels deviennent :

- surface BET élevée ;
- porosité ;
- distribution des pores ;
- stabilité mécanique.

Tous les biochars agricoles ne conviennent pas à cet usage.

---

# Crédits carbone

Si l'objectif est la séquestration du carbone :

vérifier :

- la stabilité ;
- le rapport H/Corg ;
- la certification carbone ;
- la traçabilité de la biomasse ;
- le procédé de fabrication.

Ces éléments conditionnent généralement l'éligibilité aux mécanismes de certification.

---

# Coût global

Le coût réel d'un biochar comprend :

- prix d'achat ;
- transport ;
- stockage ;
- broyage éventuel ;
- mélange ;
- application ;
- suivi.

Un produit légèrement plus cher peut être économiquement plus performant grâce à de meilleures propriétés.

# Vers un Passeport Numérique

À terme, chaque lot pourrait être accompagné d'un Passeport Numérique Universel du Biochar (PNUB), regroupant :

- les caractéristiques techniques ;
- les analyses de laboratoire ;
- les certifications ;
- les usages recommandés ;
- les performances mesurées.

Un tel outil simplifierait considérablement la comparaison entre fournisseurs.

---

# Conclusion

Le développement du marché mondial du biochar reposera autant sur la qualité des produits que sur la confiance des utilisateurs.

Cette confiance passe par :

- des données transparentes ;
- des analyses reproductibles ;
- des certifications adaptées ;
- une traçabilité complète.

Un acheteur bien informé ne recherche pas le biochar le moins cher.

Il recherche le biochar offrant la meilleure valeur technique, économique et environnementale pour son projet.

---

## À retenir

✓ Définir précisément l'application recherchée.

✓ Exiger des analyses complètes.

✓ Vérifier la traçabilité de la biomasse.

✓ Comparer les performances plutôt que le seul prix.

✓ Privilégier les fournisseurs transparents.

✓ Réaliser des essais lorsque les volumes sont importants.
