# Chapitre 5 — Vers une Bourse Mondiale du Biochar

> Version 1.0 — Juillet 2026

---

# Introduction

Le pétrole possède ses places de marché.

Le gaz naturel possède ses places de marché.

Les métaux disposent de marchés organisés.

Les crédits carbone disposent désormais de plusieurs plateformes internationales.

Le biochar, malgré sa croissance rapide, reste essentiellement commercialisé par contrats privés, appels d'offres ou négociations directes.

Cet atlas propose un concept prospectif :

**la création d'une Bourse Mondiale du Biochar (BMB).**

Il ne s'agit pas d'un projet existant mais d'une vision destinée à accompagner la structuration du marché mondial.

---

# Pourquoi une bourse ?

Aujourd'hui, plusieurs difficultés persistent :

- absence de prix mondial de référence ;
- qualité variable des biochars ;
- manque de transparence ;
- faible liquidité ;
- difficulté de comparer les produits.

Une place de marché commune pourrait améliorer la transparence des échanges.

---

# Les objectifs

Une Bourse Mondiale du Biochar pourrait permettre :

- une cotation internationale ;
- une comparaison normalisée des produits ;
- une meilleure visibilité des prix ;
- une amélioration de la liquidité ;
- une réduction des asymétries d'information.

---

# Une logique comparable aux matières premières

Le biochar présente plusieurs caractéristiques communes avec les marchés de matières premières :

| Critère | Biochar |
|----------|----------|
| Produit industriel | Oui |
| Production mondiale | Oui |
| Normes de qualité | En développement |
| Traçabilité | En progression |
| Cotation mondiale | Non (à ce jour) |

Contrairement au pétrole ou au cuivre, le biochar n'est cependant pas un produit homogène : ses propriétés varient fortement selon la biomasse, le procédé et l'usage visé. Les standards internationaux (EBC, WBC, IBI) contribuent progressivement à harmoniser cette diversité. :contentReference[oaicite:0]{index=0}

---

# Des familles de cotation

Plutôt qu'un prix unique, plusieurs indices pourraient coexister.

Exemple :

| Code | Marché |
|------|---------|
| BA | Agriculture |
| BC | Construction |
| BF | Filtration |
| BI | Industrie |
| BS | Séquestration carbone |

Chaque catégorie disposerait de sa propre référence de marché.

---

# Les critères d'admission

Pour être coté, un lot pourrait comporter :

- une analyse de laboratoire ;
- une certification reconnue ;
- un Passeport Numérique Universel du Biochar (PNUB) ;
- un Indice Universel de Qualité (IUQB) ;
- une déclaration d'origine.

Ces éléments sont proposés comme une architecture conceptuelle et compléteraient les certifications existantes, sans s'y substituer.

---

# Les acteurs

Une telle plateforme pourrait réunir :

- producteurs ;
- acheteurs industriels ;
- agriculteurs ;
- négociants ;
- laboratoires ;
- organismes certificateurs ;
- investisseurs.

---

# Les informations publiques

Chaque lot pourrait publier :

| Donnée | Disponible |
|----------|------------|
| Biomasse | Oui |
| Pays d'origine | Oui |
| Producteur | Oui |
| Certification | Oui |
| Surface BET | Oui |
| H/Corg | Oui |
| O/Corg | Oui |
| Cendres | Oui |
| Prix | Oui |
| Disponibilité | Oui |

---

# Une place pour les crédits carbone

Le biochar est également un support de retrait durable du carbone.

La plateforme pourrait référencer, lorsque les référentiels le permettent :

- les certificats carbone associés ;
- la quantité de CO₂ retirée ;
- la méthode de certification utilisée ;
- la durée estimée du stockage.

Le développement de ces mécanismes dépend toutefois des standards de certification carbone, qui évoluent rapidement. :contentReference[oaicite:1]{index=1}

---

# Une plateforme numérique ouverte

La plateforme pourrait proposer :

- des données ouvertes ;
- des API publiques ;
- des historiques de prix ;
- des statistiques ;
- des graphiques de marché.

Cela faciliterait les analyses économiques et scientifiques.

---

# Les bénéfices

Une Bourse Mondiale du Biochar pourrait :

- améliorer la confiance ;
- réduire les coûts de transaction ;
- accélérer les investissements ;
- favoriser les échanges internationaux ;
- encourager la standardisation.

---

# Les limites

Le biochar ne constitue pas une matière première parfaitement homogène.

Deux lots produits à partir de biomasses différentes peuvent répondre à des usages très distincts.

Une bourse ne pourrait donc fonctionner qu'avec :

- des classifications techniques robustes ;
- des méthodes analytiques harmonisées ;
- une forte transparence des données.

---

# Perspectives

À long terme, une telle plateforme pourrait être reliée :

- aux Passeports Numériques Universels du Biochar (PNUB) ;
- à l'Indice Universel de Qualité du Biochar (IUQB) ;
- aux certifications internationales ;
- aux registres de crédits carbone.

Elle formerait un écosystème numérique complet permettant de suivre chaque lot depuis sa production jusqu'à son utilisation finale.

---

# Conclusion

Le biochar est en train de devenir une matière stratégique pour l'agriculture, les matériaux, la filtration et les solutions de retrait du carbone.

À mesure que le marché se développe, la création d'outils favorisant la transparence, la comparabilité et la liquidité pourrait accélérer son industrialisation.

La **Bourse Mondiale du Biochar** est une proposition prospective de l'auteur. Elle ne correspond pas à une infrastructure existante, mais constitue une vision de ce que pourrait devenir un marché mondial mature, structuré autour de standards de qualité, de passeports numériques et d'une information ouverte.
