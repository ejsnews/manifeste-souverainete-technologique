# Chapitre 5 — L'Indice Universel de Qualité du Biochar (IUQB)

> Version 1.0 — Juillet 2026

---

# Introduction

Le marché mondial du biochar connaît une croissance rapide.

Pourtant, il n'existe aujourd'hui aucun indicateur simple permettant de comparer rapidement deux biochars produits dans des pays différents.

Les certificats attestent de la conformité à un référentiel.

Les analyses de laboratoire décrivent les propriétés physico-chimiques.

Mais aucun indice synthétique ne permet de répondre immédiatement à une question essentielle :

> **Quelle est la qualité globale de ce biochar ?**

Ce chapitre propose un concept prospectif : **l'Indice Universel de Qualité du Biochar (IUQB)**.

Il ne constitue pas une norme officielle, mais une méthode de notation ouverte destinée à faciliter la comparaison entre biochars.

---

# Philosophie

L'objectif n'est pas de remplacer :

- les certifications ;
- les analyses de laboratoire ;
- les essais industriels.

L'indice constitue une synthèse destinée aux utilisateurs.

Le principe est comparable à l'étiquette énergétique d'un bâtiment ou à une notation technique.

---

# Les familles de critères

L'indice repose sur cinq domaines.

| Domaine | Pondération proposée |
|----------|--------------------:|
| Qualité physico-chimique | 30 % |
| Stabilité du carbone | 25 % |
| Performances techniques | 20 % |
| Traçabilité | 15 % |
| Durabilité environnementale | 10 % |

Ces pondérations sont proposées à titre de discussion et pourraient évoluer.

---

# Critère 1 : qualité physico-chimique

Les paramètres retenus pourraient comprendre :

- carbone fixe ;
- H/Corg ;
- O/Corg ;
- humidité ;
- teneur en cendres ;
- densité.

Chaque propriété recevrait une note.

---

# Critère 2 : stabilité

La stabilité du carbone pourrait être estimée à partir :

- du rapport H/Corg ;
- du rapport O/Corg ;
- de la température de thermolyse ;
- de la nature de la biomasse.

Un biochar destiné à la séquestration durable obtiendrait une meilleure note.

---

# Critère 3 : performances

Les performances pourraient intégrer :

- surface BET ;
- porosité ;
- granulométrie ;
- résistance mécanique ;
- homogénéité.

Les critères exacts dépendraient de l'application.

---

# Critère 4 : traçabilité

Un biochar bénéficierait d'une meilleure notation s'il dispose :

- d'un passeport numérique ;
- d'une traçabilité complète ;
- d'analyses indépendantes ;
- d'un historique documentaire.

Les futurs passeports numériques de produits (Digital Product Passports) pourraient fournir une partie de ces informations de manière standardisée. :contentReference[oaicite:0]{index=0}

---

# Critère 5 : durabilité

Ce critère pourrait intégrer :

- origine durable de la biomasse ;
- distance de transport ;
- récupération de chaleur ;
- analyse du cycle de vie ;
- valorisation des coproduits.

---

# Calcul de l'indice

L'indice serait compris entre :

```
0 et 100
```

Exemple :

```
IUQB = 91 /100
```

---

# Classification

| Indice | Classe |
|---------|---------|
| 95–100 | A+ |
| 90–94 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |

---

# Utilisations possibles

L'indice pourrait faciliter :

- la comparaison de biochars concurrents ;
- les appels d'offres ;
- les publications scientifiques ;
- les achats industriels ;
- les investissements.

Il pourrait également être affiché dans un futur passeport numérique.

---

# Les limites

Aucun indice ne peut résumer parfaitement un matériau complexe.

Deux biochars ayant un même IUQB peuvent présenter des performances très différentes selon l'usage recherché.

L'indice ne remplace donc ni les essais en laboratoire ni les essais applicatifs.

---

# Perspectives

À terme, l'indice pourrait être calculé automatiquement à partir :

- des résultats de laboratoire ;
- du Passeport Numérique Universel du Biochar ;
- des certificats de conformité ;
- des données de production.

Cette automatisation serait cohérente avec l'évolution des **Digital Product Passports**, qui visent à structurer et partager des données techniques tout au long du cycle de vie des produits. :contentReference[oaicite:1]{index=1}

---

# Conclusion

L'Indice Universel de Qualité du Biochar est une proposition prospective destinée à ouvrir le débat.

Il ne cherche pas à remplacer les normes existantes.

Son objectif est de fournir un langage simple, reproductible et compréhensible permettant d'évaluer rapidement la qualité globale d'un biochar, tout en restant compatible avec les futurs passeports numériques et les référentiels internationaux.
