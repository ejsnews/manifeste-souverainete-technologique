# Chapitre 5 — L'Indice Mondial du Prix du Biochar (IMPB)

> Version 1.0 – Juillet 2026

---

# Introduction

L'un des principaux freins au développement du marché mondial du biochar est l'absence d'un prix de référence international.

Aujourd'hui :

- chaque contrat est négocié individuellement ;
- chaque pays possède ses propres usages ;
- les qualités diffèrent fortement ;
- les marchés demeurent peu transparents.

À la différence du pétrole (Brent), du gaz naturel (TTF), de l'or (LBMA) ou du cuivre (LME), le biochar ne dispose pas d'un indice mondial de référence.

Ce chapitre propose la création d'un **Indice Mondial du Prix du Biochar (IMPB)**.

Cette proposition est prospective.

---

# Objectifs

L'IMPB aurait pour mission :

- suivre l'évolution du marché mondial ;
- comparer les grandes régions ;
- améliorer la transparence ;
- fournir un indicateur économique aux investisseurs ;
- servir de référence pour certains contrats.

---

# Un indice plutôt qu'un prix unique

Il n'existe pas un biochar.

Il existe des centaines de biochars.

L'IMPB serait donc calculé comme un indice composite.

---

# Les familles de biochars

| Code | Marché |
|------|---------|
| BA | Agriculture |
| BC | Construction |
| BF | Filtration |
| BI | Industrie |
| BS | Séquestration carbone |

Chaque famille posséderait son propre indice.

---

# Les régions

L'indice pourrait être publié pour :

| Région | Code |
|---------|------|
| Europe | EU |
| Amérique du Nord | NA |
| Amérique du Sud | SA |
| Afrique | AF |
| Moyen-Orient | ME |
| Asie | AS |
| Océanie | OC |

---

# Exemple

```
BC-EU = 126
```

signifierait :

Indice Construction Europe.

---

# Les données utilisées

Le calcul pourrait intégrer :

- prix réellement observés ;
- qualité (IUQB) ;
- certification ;
- biomasse ;
- disponibilité ;
- coûts logistiques.

---

# Une moyenne pondérée

L'indice pourrait être calculé à partir :

Prix × Volume × Qualité

Les pondérations seraient publiques afin de garantir la transparence.

---

# Publication

Une publication hebdomadaire pourrait comprendre :

- indice mondial ;
- indices régionaux ;
- indices sectoriels ;
- historique ;
- évolution annuelle.

---

# Applications

L'IMPB pourrait être utilisé par :

- producteurs ;
- industriels ;
- investisseurs ;
- banques ;
- chercheurs ;
- gouvernements.

---

# Couplage avec le PNUB

Chaque lot vendu pourrait publier :

- son Passeport Numérique Universel du Biochar ;
- son IUQB ;
- son prix de transaction.

L'IMPB serait alors calculé automatiquement.

---

# Une gouvernance indépendante

La crédibilité de l'indice dépendrait de sa gouvernance.

Une fondation internationale à but non lucratif pourrait réunir :

- universités ;
- laboratoires ;
- producteurs ;
- industriels ;
- certificateurs ;
- organisations internationales.

Ses missions seraient :

- définir la méthodologie ;
- publier les données ;
- auditer les calculs ;
- assurer l'indépendance de l'indice.

Cette approche s'inspire de la gouvernance adoptée par plusieurs indices de référence dans les marchés de matières premières et de l'énergie.

---

# Open Data

Les données pourraient être accessibles :

- par API ;
- en CSV ;
- en JSON ;
- sous licence ouverte.

Les chercheurs pourraient ainsi développer :

- modèles économiques ;
- prévisions ;
- cartes mondiales ;
- analyses statistiques.

---

# Perspectives

À terme, l'IMPB pourrait devenir l'un des principaux indicateurs du marché mondial du biochar.

Les contrats internationaux pourraient y faire référence de la même manière que d'autres secteurs utilisent aujourd'hui les indices du pétrole, des métaux ou du gaz.

---

# Conclusion

Le biochar entre progressivement dans une phase d'industrialisation mondiale.

La création d'un **Indice Mondial du Prix du Biochar (IMPB)** constituerait une étape importante vers un marché plus transparent, plus liquide et plus accessible.

Associé au **Passeport Numérique Universel du Biochar (PNUB)**, à l'**Indice Universel de Qualité du Biochar (IUQB)** et aux principales certifications, il pourrait former le socle d'un futur écosystème international du biochar.
