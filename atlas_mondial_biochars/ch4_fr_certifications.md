# Chapitre 4 — Certifications et normes internationales du biochar

> Version 1.0 — Juillet 2026

## Pourquoi certifier un biochar ?

Un biochar est destiné à des usages très variés :

- agriculture ;
- élevage ;
- matériaux de construction ;
- filtration ;
- stockage permanent du carbone.

Dans chacun de ces domaines, les utilisateurs doivent pouvoir connaître précisément :

- son origine ;
- sa composition ;
- son procédé de fabrication ;
- ses performances ;
- ses éventuels contaminants.

Les certifications apportent cette confiance.

# Les principales certifications

| Certification | Zone principale | Domaine |
|---------------|----------------|----------|
| EBC | Europe | Biochar |
| WBC | International | Biochar |
| IBI | International | Analyses |
| Puro.earth | International | Retrait carbone |
| CSI | International | Certification EBC/WBC |

Les référentiels EBC (European Biochar Certificate) et WBC (World Biochar Certificate) sont aujourd'hui parmi les principaux standards de qualité pour la production de biochar, avec des exigences portant sur les matières premières, le procédé, les analyses et la traçabilité. :contentReference[oaicite:0]{index=0}

# European Biochar Certificate (EBC)

Créé en 2012, l'EBC est l'un des premiers systèmes indépendants de certification du biochar.

Il couvre :

- les biomasses autorisées ;
- le procédé de thermolyse ;
- les analyses en laboratoire ;
- les contaminants ;
- la traçabilité ;
- la documentation des lots.

Les propriétés contrôlées incluent notamment le carbone organique, les rapports H/Corg et O/Corg, les métaux lourds, les HAP, le pH, la conductivité électrique et d'autres paramètres physico-chimiques. :contentReference[oaicite:1]{index=1}

# Biomasses admissibles

Les certifications imposent généralement une liste positive des biomasses autorisées.

Exemples :

- bois non traité ;
- résidus forestiers ;
- bambou ;
- coques végétales ;
- résidus agricoles propres.

Les matières contaminées ou contenant des substances interdites sont exclues. :contentReference[oaicite:2]{index=2}

---

# Les seuils techniques

Quelques critères fréquemment utilisés :

| Critère | Valeur indicative |
|----------|------------------:|
| H/Corg | < 0,7 |
| O/Corg | < 0,4 |
| Métaux lourds | selon les limites du référentiel |
| HAP | sous les seuils réglementaires |

Ces valeurs servent à évaluer le degré de carbonisation et la stabilité du biochar. Les seuils exacts dépendent de la catégorie de certification. :contentReference[oaicite:3]{index=3}

---

# Les contaminants

Les analyses portent notamment sur :

- Cadmium (Cd)
- Mercure (Hg)
- Plomb (Pb)
- Arsenic (As)
- Chrome (Cr)
- Nickel (Ni)

ainsi que sur les HAP.

Ces contrôles sont essentiels pour les usages agricoles et les matériaux.

---

# Traçabilité

Une certification sérieuse permet généralement de relier un lot à :

- la biomasse utilisée ;
- la date de production ;
- le procédé ;
- les résultats d'analyse ;
- les certificats.

Les systèmes EBC/WBC prévoient notamment une identification des lots et une traçabilité documentaire. :contentReference[oaicite:4]{index=4}

---

# Intérêt économique

Une certification peut faciliter :

- l'accès à certains marchés ;
- la confiance des clients ;
- la valorisation des crédits carbone ;
- la commercialisation internationale.

Elle constitue souvent un élément de différenciation pour les producteurs.

---

# Limites

Une certification ne garantit pas qu'un biochar est optimal pour toutes les applications.

Deux biochars certifiés peuvent présenter :

- des surfaces BET différentes ;
- des porosités différentes ;
- des densités différentes ;
- des performances très différentes selon l'usage.

La certification est donc un socle de qualité, mais elle ne remplace pas une caractérisation adaptée à chaque application.

---

# Vers une normalisation mondiale ?

À mesure que le marché du biochar se développe, plusieurs tendances se dessinent :

- harmonisation des méthodes analytiques ;
- amélioration de la traçabilité ;
- intégration des certificats carbone ;
- normalisation des fiches techniques ;
- développement de standards internationaux.

Une convergence progressive entre les référentiels faciliterait les échanges commerciaux et la comparaison des performances.

---

# Conclusion

Les certifications constituent aujourd'hui un élément essentiel du développement du marché mondial du biochar.

Elles améliorent :

- la confiance ;
- la qualité ;
- la sécurité ;
- la traçabilité ;
- l'accès aux marchés.

À terme, elles devraient être complétées par des fiches techniques normalisées permettant de comparer objectivement les propriétés des biochars selon leurs usages.
